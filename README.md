# Hashbit Projects

A collection of web-development assignments and practice projects completed as part of Hashbit learning exercises.

## Included projects

- **Calculator** — React calculator interface
- **IPL Table** — React-based IPL points-table UI
- **Movie Booking** — React movie-booking application with React Router
- **ToDoApp** — React task-management application
- **Assignment 1–4** — HTML, CSS, JavaScript, and DOM-manipulation exercises
- **JavaScript Practice** — JavaScript fundamentals and problem-solving exercises

## Tech stack

HTML, CSS, JavaScript, React, Vite, and React Router.

## Run a React project locally

Each React project has its own folder and `package.json`.

```bash
cd "Movie Booking" # or Calculator, IPL TABLE, or ToDoApp
npm install
npm run dev
```

Static HTML/CSS/JavaScript assignments can be opened directly in a browser.
